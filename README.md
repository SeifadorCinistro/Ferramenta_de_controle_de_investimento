# Ferramenta de controle de investimento

Ferramenta em Excel para simulação de investimento imobiliário.

Ferramenta de cunho didático em Excel para simulação de investimento imobiliário.

A ferramenta contém tabelas suportadas por fórmulas e funções.

A ferramenta permite:

- Planilha principal (Simulador);
- Planilha de apoio;
- Planilha com as perguntas de negócios aplicadas.

A planilha principal permite a simulação de um investimento mensal ao longo do tempo, que pode ser definido pelo usuário.

Também permite a simulação de diferentes perfis de investimento.

A taxa de juros também pode ser definida pelo usuário.

A ferramenta também possui um gráfico de apoio.

## Ferramenta utilizada

Microsoft Excel 2013.
